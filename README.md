# Лабораторна робота №5. Обробка текстових даних, рядкові методи та регулярні вирази

**Виконала:** СТУДЕНТКА ГРУПИ ЕІ-24-1 МУНТЯН М.О.  
**Варіант:** 20

## Мета роботи

Опанування практичних навичок обробки, очищення, валідації та структурування текстових даних мовою Python. Використання рядкових методів, регулярних виразів модуля `re` та форматування результатів за допомогою f-рядків.

## Завдання 1. Очищення текстових даних

**Модуль:** `text_sanitizer.py`

**Реалізовані операції:**
- Видалення зайвих пробілів методом `strip()`.
- Нормалізація текстових рядків.
- Обробка роздільників між полями журналу.

## Завдання 2. Синтаксичний аналіз журналу Git Audit

**Модуль:** `log_parser.py`

**Структура журналу:**
- `Commit_Hash` — хеш коміту (40 шістнадцяткових символів).
- `Author_Name` — ім'я автора.
- `Email` — електронна адреса.
- `Timestamp_ISO` — дата та час коміту.
- `Message` — повідомлення коміту.

**Реалізовані операції:**
- Зчитування текстового журналу з файлу `input_logs.txt`.
- Очищення вхідних рядків.
- Використання `re.compile()` для створення регулярного виразу.
- Вилучення полів за допомогою іменованих груп `groupdict()`.
- Перевірка правильності електронної адреси.
- Перевірка повідомлень за стандартом Conventional Commits.
- Формування діагностичної таблиці за допомогою f-рядків.
- Підрахунок коректних і некоректних записів.
- Вимірювання часу виконання програми.

## Результати виконання

Для тестування використано реальний запис коміту з GitHub.

- Усього проаналізовано комітів: 1.
- Коректних комітів: 0.
- Некоректних комітів: 1.
- Перевірка email: OK.
- Перевірка Conventional Commits: ERROR.

Повідомлення `Add files via upload` не відповідає стандарту Conventional Commits, оскільки не містить необхідного префікса типу коміту.

Програма успішно розпізнала дані та виявила невідповідність повідомлення встановленому формату.
